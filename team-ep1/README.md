# บันทึกฝึกงานของทีม | EP.1 — ค่อย ๆ กล้าทีละนิด

หนังสั้นแอนิเมชัน 2D แนวตั้ง 9:16 (1080×1920, 30 fps) ใช้เสียงบรรยายของ “ทีม” เป็นเสียงหลักและเป็นตัวกำหนดความยาวทั้งเรื่อง

| ไฟล์ | คืออะไร |
|---|---|
| `output/team-ep1.mp4` | วิดีโอสุดท้าย H.264 + AAC 48 kHz มีเสียงบรรยายครบและซับไทยฝังในภาพ |
| `output/team-ep1.th.srt` | ซับไทยแยกไฟล์ ใช้กับแพลตฟอร์มที่รองรับซับแบบเปิด/ปิดได้ |
| `index.html` | ตัวเล่นบนเว็บ วาดภาพสดและซิงก์กับเสียง เปิดผ่านเว็บเซิร์ฟเวอร์ได้เลย (มีแถบเลื่อนเวลา) |
| `js/` | ไฟล์ต้นฉบับที่แก้ไขได้ทั้งหมด (ดูหัวข้อถัดไป) |
| `audio/narration.wav` | เสียงบรรยายต้นฉบับ ไม่ได้ตัด เร่ง หรือแก้ไข |

## เสียงบรรยาย

- ความยาวจริง **209.16 วินาที (3:29.16)** · WAV 24 kHz mono
- วิดีโอยาว 6,275 เฟรม (209.17 วิ) เสียงบรรยายใส่ครบทั้งไฟล์
- ไม่ได้เพิ่มเพลงหรือเสียงอื่น เพราะไม่มีไฟล์ดนตรีที่มีสิทธิ์ใช้งาน เสียงจึงเป็นเสียงบรรยายอย่างเดียวตามที่บรีฟอนุญาต
- ถอดเสียงด้วย Whisper large-v3 แบบออฟไลน์ ช่วงเวลาของซับแต่ละท่อนมาจากช่วงเงียบจริงในไฟล์เสียง

## โครงสร้างไฟล์ต้นฉบับ

- `js/core.js` — ระบบตัวละครแบบแยกข้อต่อ (ศีรษะ ตา คิ้ว ปาก ลำตัว แขน ข้อศอก มือ ขา เข่า) มี IK ให้มือแตะวัตถุตรงตำแหน่ง มีท่าเดิน การกะพริบตา และการหายใจ · ชุดตัวละคร `CAST` (ทีม ครูปีใหม่ ครูแพม ครูกร) และ `KIDS`
- `js/sets.js` — ฉากที่วาดใหม่จากรูปสถานที่: หน้าร้าน ป้ายผนังไม้ ห้องเรียน SPIKE ห้องรับรอง ห้อง Duplo และห้องพักของทีม (ฉากสมมติ)
- `js/inserts.js` — ภาพใกล้ เช่น มือ iPad ฮับ สมุดโน้ต ข้าวกล่อง และโค้ด
- `js/engine.js` — กล้อง การเกรดสี ภาพเปลี่ยนฉาก และเลเยอร์ตัวอักษร (ซับ ป้ายเวลา ป้ายชื่อ ข้อความในความคิด ชื่อเรื่อง)
- `js/shots.js` — ไทม์ไลน์ทั้งเรื่อง แต่ละช็อตคือ `shot(เริ่ม, จบ, ฟังก์ชันวาด, เวลาเฟด)` และกำหนดท่าทางด้วยคีย์เฟรม
- `js/subtitles.js` — ซับไทย `[เริ่ม, จบ, ข้อความ]` ไม่เกิน 2 บรรทัดต่อช่วง
- ตัวอักษรอยู่บนแคนวาสแยก (`#text`) วางซ้อนบนภาพ (`#scene`) · ซับอยู่ที่ประมาณ y≈1490 เว้นพื้นที่ด้านล่าง ~360px สำหรับหน้าจอมือถือ
- ฟอนต์ Mitr, Sarabun, Kanit (SIL Open Font License) อยู่ในโฟลเดอร์ `fonts/`

## เรนเดอร์ใหม่

```bash
# ต้องมี Node 18+, Playwright (Chromium) และ ffmpeg
node render/render.js --workers 4          # → output/team-ep1.mp4
node render/srt.js > output/team-ep1.th.srt
# ดูตัวอย่างบางช่วง: node render/render.js --from 55 --to 70 --out output/preview.mp4
```

ตัวเรนเดอร์จะเปิด `index.html?render=1` ในเบราว์เซอร์แบบไม่มีหน้าจอ วาดทีละเฟรมตามเวลาที่กำหนด (`window.__frame(t)`) แล้วใช้ ffmpeg รวมเฟรมเข้ากับเสียงบรรยายต้นฉบับ

## หมายเหตุเรื่องคำถอดเสียง

ข้อความในซับมาจากการถอดเสียงอัตโนมัติ แล้วตรวจซ้ำในบางช่วง มีคำที่ควรให้เจ้าของเสียงยืนยันดังนี้

- 1:36 “คนที่นี่ส่วนใหญ่มีพื้นฐานด้าน**ครูมา**” — เครื่องถอดได้ “ครูหมา/ขู่หมา” จึงตีความเป็น “ครูมา” (หากต้นฉบับคือ “ครุศาสตร์” ให้แก้ใน `js/subtitles.js`)
- 2:24 “ผมชอบ**บ่น**กับตัวเองว่า” — ถอดซ้ำได้คำเดิม
